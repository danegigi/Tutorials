Go's type system is small and explicit. Learn declarations and zero values, the basic and composite types, and functions — including multiple returns and closures, two features you'll use constantly.

Declaring variables

Beginner Three forms, from most to least explicit:

var count int = 10      // full form
var count = 10          // type inferred from the value
count := 10             // short form — only inside functions

// Zero values: every type has one, so there are no "uninitialized" variables
var n int        // 0
var s string     // "" (empty, never nil)
var ok bool      // false
var p *int       // nil
Common mistake: declaring a variable you never use. Go makes this a compile error ("declared and not used"), not a warning. Same for unused imports. This is deliberate — it keeps code clean — but surprises newcomers.

Composite types

// Arrays: fixed length, value type
var a [3]int = [3]int{1, 2, 3}

// Slices: dynamic view over an array — the workhorse
nums := []int{1, 2, 3}
nums = append(nums, 4)        // → [1 2 3 4]
sub := nums[1:3]              // → [2 3] (shares backing array!)

// Maps: hash tables
ages := map[string]int{"alice": 30}
ages["bob"] = 25
v, ok := ages["carol"]        // ok=false, v=0 (zero value)
delete(ages, "bob")

// Structs: grouped fields
type Point struct{ X, Y int }
p := Point{X: 1, Y: 2}
A slice is a 3-word header (pointer, length, capacity). append may reallocate when capacity is exceeded; until then, slices sharing a backing array see each other's writes. When in doubt, copy() into a fresh slice.

Functions

func add(a, b int) int { return a + b }

// Multiple return values — the idiomatic (result, error) pair
func div(a, b int) (int, error) {
	if b == 0 {
		return 0, fmt.Errorf("divide by zero")
	}
	return a / b, nil
}

q, err := div(10, 2)
if err != nil { /* handle */ }

// Named returns + naked return (use sparingly, for short functions)
func split(sum int) (x, y int) {
	x = sum * 4 / 9
	y = sum - x
	return
}

// Variadic
func sum(nums ...int) int {
	t := 0
	for _, n := range nums { t += n }
	return t
}
sum(1, 2, 3)        // 6
sum(nums...)        // spread a slice

Closures

Intermediate Functions are values and can capture variables from their enclosing scope:

func counter() func() int {
	n := 0
	return func() int { n++; return n }  // closes over n
}

next := counter()
fmt.Println(next(), next(), next())  // → 1 2 3
Classic trap (pre-Go 1.22): capturing a loop variable by reference. Since Go 1.22 each iteration has its own loop variable, so for i := range xs { go func(){ use(i) }() } is now safe. On older Go, you had to shadow with i := i inside the loop.

Exercises

  • Write func minmax(nums []int) (min, max int) using named returns; handle the empty-slice case.
  • Demonstrate the slice-aliasing gotcha: take s[1:3], mutate it, and show the original changed.
  • Build a memoizing closure: func memoize(f func(int) int) func(int) int that caches results in a map.

Mini-project: a word-frequency counter

Read text from stdin, split on whitespace, and build a map[string]int of counts. Then produce a []struct{Word string; N int}, and print the top 10 — exercising slices, maps, structs, and functions together. (You'll sort it properly after the Control Flow and stdlib lessons.)
