Reading and writing files and encoding JSON are the two I/O chores every program needs. Go's os, io, and encoding/json packages make both uniform through the io.Reader/io.Writer interfaces.

Reading files

// Whole file into memory (simple, for small files)
data, err := os.ReadFile("config.yaml")
if err != nil { return err }
fmt.Println(string(data))

// Streaming line by line (for large files — constant memory)
f, err := os.Open("big.log")
if err != nil { return err }
defer f.Close()

scanner := bufio.NewScanner(f)
for scanner.Scan() {
	line := scanner.Text()
	process(line)
}
if err := scanner.Err(); err != nil { return err }
Common mistake: os.ReadFile on a multi-gigabyte file — it loads the whole thing into RAM. Stream with bufio.Scanner (lines) or io.Copy (bytes) when size is unbounded.

Writing files

// Whole file at once (0644 = rw-r--r--)
os.WriteFile("out.txt", []byte("hello\n"), 0644)

// Buffered, incremental
f, _ := os.Create("report.txt")
defer f.Close()
w := bufio.NewWriter(f)
for _, line := range lines { fmt.Fprintln(w, line) }
w.Flush()   // don't forget — buffered writers hold data until flushed

The Reader/Writer abstraction

Intermediate Files, network connections, HTTP bodies, and in-memory buffers all satisfy io.Reader/io.Writer, so one function works with all of them:

// Copy from anything readable to anything writable, streaming
io.Copy(dst, src)                       // file→file, resp.Body→file, etc.
io.Copy(os.Stdout, resp.Body)           // stream a download to the terminal

var buf bytes.Buffer                     // an in-memory Writer AND Reader
fmt.Fprintf(&buf, "n=%d", 42)
fmt.Println(buf.String())                // → n=42

Encoding JSON

type Config struct {
	Name    string   `json:"name"`
	Port    int      `json:"port"`
	Tags    []string `json:"tags,omitempty"`   // omit when empty
	secret  string   // unexported → never marshalled
}

c := Config{Name: "api", Port: 8080}
b, _ := json.Marshal(c)                  // compact
b, _ = json.MarshalIndent(c, "", "  ")   // pretty
fmt.Println(string(b))
// → { "name": "api", "port": 8080 }

Decoding JSON

var c Config
if err := json.Unmarshal(b, &c); err != nil { return err }

// Stream a decoder straight off a Reader (file, HTTP body)
f, _ := os.Open("config.json")
defer f.Close()
if err := json.NewDecoder(f).Decode(&c); err != nil { return err }

// Unknown shape → map[string]any
var raw map[string]any
json.Unmarshal(b, &raw)
Common mistakes with JSON: (1) lowercase struct fields are unexported and silently skipped — fields must be capitalized to marshal. (2) Numbers decode into float64 when the target is any, so a JSON 5 becomes 5.0. (3) Forgetting the json:"..." tag gives you the Go field name casing in the output.

Custom field handling

type Event struct {
	At time.Time `json:"at"`                       // RFC 3339 by default
	ID int       `json:"id,string"`                // marshal number AS a string
	Hidden bool  `json:"-"`                         // never serialize
}

Exercises

  • Count the lines in a large file with bufio.Scanner without loading it all into memory.
  • Round-trip a struct → JSON → struct and verify equality; then break it by lowercasing a field name.
  • Decode an HTTP JSON response directly with json.NewDecoder(resp.Body).Decode(&v).
