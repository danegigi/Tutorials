CSS controls presentation. Master the box model, selectors and the cascade, then the two modern layout systems — Flexbox and Grid — and custom properties for theming. These five ideas cover the vast majority of real styling.

The box model

Beginner Every element is a box: content, then padding, then border, then margin. The default box-sizing makes width/height apply to content only — switch it globally so padding and border are included (far more predictable):

*, *::before, *::after { box-sizing: border-box; }

.card {
  width: 300px;          /* now INCLUDES padding + border */
  padding: 16px;
  border: 1px solid #ccc;
  margin: 12px;
}
Margin collapsing surprises everyone: adjacent vertical margins merge into the larger of the two, not their sum. Two stacked elements with margin: 20px are 20px apart, not 40px. Flex/Grid gaps don't collapse — another reason to prefer them.

Selectors and specificity

h1            { }   /* type:      specificity 0,0,1 */
.btn          { }   /* class:     0,1,0 */
#main         { }   /* id:        1,0,0 */
.btn.primary  { }   /* 0,2,0 — beats a single class */
a:hover       { }   /* pseudo-class counts as a class */

When two rules match, higher specificity wins; ties go to the later rule. The cascade order is: origin/importance → specificity → source order.

Common mistake: fighting specificity with !important. It almost always makes the next override harder. Prefer a single flat class layer (the idea behind utility CSS and BEM) and keep IDs out of your selectors.

Flexbox — one-dimensional layout

.toolbar {
  display: flex;
  align-items: center;      /* cross axis (vertical here) */
  justify-content: space-between;  /* main axis */
  gap: 12px;                /* spacing between items — no margin hacks */
}
.toolbar .spacer { flex: 1; }   /* push the rest to the right */

Flexbox excels at rows or columns of items: navbars, button groups, centering. flex: 1 on an item makes it grow to fill free space.

Grid — two-dimensional layout

.gallery {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(220px, 1fr));
  gap: 16px;
}

/* Named areas for a page shell */
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-areas: "sidebar main";
}
.sidebar { grid-area: sidebar; }
.main    { grid-area: main; }

The auto-fill + minmax pattern is the single most useful responsive layout: it fits as many columns as will hold their minimum width, with no media queries.

Custom properties (CSS variables)

Intermediate Variables cascade and can be swapped at runtime — the foundation of theming (including the dark/light toggle on this very site):

:root {
  --bg: #ffffff;
  --text: #1b2130;
  --accent: #0369a1;
}
:root[data-theme="dark"] {
  --bg: #0d1117;
  --text: #e6edf3;
  --accent: #38bdf8;
}
body { background: var(--bg); color: var(--text); }
a    { color: var(--accent); }
/* Toggle the theme by setting data-theme on <html> in JS — every var updates */

Exercises

  • Build a navbar with Flexbox: logo left, links right, vertically centered, with a gap.
  • Make a responsive card grid with repeat(auto-fill, minmax(…)) — no media queries.
  • Implement a dark/light theme with custom properties toggled by a data-theme attribute.

Mini-project: style the resume

Take the semantic resume from the HTML lesson and style it: a Grid page shell (sidebar + main), Flexbox for the contact row, custom properties for colors with a dark mode, and a readable type scale. Keep specificity flat (one class layer) and prove it looks right at 360px and 1200px wide.
