Install Go, learn the one command you'll use for everything (go), and wire up the formatting and vetting tools that keep Go code uniform across every project and team.

Install Go

Beginner Download the installer for your OS from the official site, or use a package manager. Verify the install prints a version:

# macOS (Homebrew)
brew install go

# Debian/Ubuntu — prefer the official tarball over apt for an up-to-date Go
curl -LO https://go.dev/dl/go1.23.0.linux-amd64.tar.gz
sudo rm -rf /usr/local/go && sudo tar -C /usr/local -xzf go1.23.0.linux-amd64.tar.gz
export PATH=$PATH:/usr/local/go/bin   # add to ~/.profile to persist

# Verify
go version
# → go version go1.23.0 darwin/arm64
Go releases every ~6 months and keeps strong backward compatibility (the "Go 1 compatibility promise"). Staying on a recent version is low-risk and gets you new stdlib and tooling.

The go command does everything

Unlike ecosystems with a dozen separate tools, Go ships one command. The subcommands you'll use daily:

CommandWhat it does
go run .Compile and run the current package in one step (no binary left behind).
go buildCompile to a binary in the current directory.
go test ./...Run every test in the module.
go fmt ./...Rewrite source in the canonical format.
go vet ./...Report suspicious constructs the compiler accepts but are likely bugs.
go mod tidyAdd missing and remove unused module dependencies.
go install pkg@latestBuild and install a command into $GOBIN.
go doc fmt.PrintlnPrint documentation for a symbol, offline.

Your first program

mkdir hello && cd hello
go mod init example.com/hello     # creates go.mod
cat > main.go <<'EOF'
package main

import "fmt"

func main() {
	fmt.Println("Hello, Go!")
}
EOF
go run .
# → Hello, Go!

Every executable lives in package main and starts at func main(). The module path (example.com/hello) is the import prefix for your own packages — it does not need to be a real URL unless you publish the module.

Formatting and vetting are not optional

Beginner Go has exactly one canonical format, enforced by gofmt. There are no style debates: tabs for indentation, specific brace placement, aligned struct fields. Your editor should format on save.

gofmt -l .        # list files that are NOT formatted (empty = all good)
gofmt -w .        # rewrite them in place
go vet ./...      # static analysis: printf format mismatches, unreachable code, etc.
Common mistake: committing unformatted code. CI pipelines routinely fail on gofmt -l . returning any file. Set your editor to run gofmt (or goimports, which also fixes imports) on save and this never bites you.

goimports: formatting + import management

go install golang.org/x/tools/cmd/goimports@latest
goimports -w .    # formats AND adds/removes import lines to match usage

Environment: GOPATH is (mostly) history

Before Go 1.11 all code had to live under a single $GOPATH/src tree. With modules (the default since Go 1.16) your project lives anywhere. The variables still worth knowing:

VariableMeaning
GOPATHWhere the module cache and installed binaries live (default ~/go).
GOBINWhere go install puts binaries (default $GOPATH/bin — add it to PATH).
GOOS / GOARCHTarget OS/arch for cross-compilation (see Deployment).
GOFLAGSDefault flags for every go command, e.g. -mod=readonly.
 
go env            # print the whole resolved environment
go env GOPATH     # just one value
go env -w GOBIN=$HOME/.local/bin   # persist a setting

Exercises

  • Run go env GOVERSION GOOS GOARCH and note your toolchain and target.
  • Intentionally mis-indent main.go, then fix it with gofmt -w . and watch the diff.
  • Add a line fmt.Printf("%d\n", "oops") and run go vet ./... — read the format-mismatch warning it produces.

Mini-project: a reproducible dev setup

Create a Makefile that standardizes the common tasks so every contributor runs the same checks:

# Makefile
.PHONY: fmt vet test run
fmt:  ; gofmt -w . && goimports -w .
vet:  ; go vet ./...
test: ; go test ./...
run:  ; go run .
check: fmt vet test   # run before every commit

Now make check formats, vets, and tests in one step — the foundation every later Go lesson builds on.
